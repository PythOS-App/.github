# Welcome to PythOS!

PythOS is a community project to make a system from Python, led by @captainawesomejnr . 

The main repository is simply called _PythOS_ (pinned below), and it holds the main application.

## How do I make a contribution?
You can contribute in one of two ways:

1. **Open a PR:** If you find a bug or want to add a feature and can make a fix, you can open a pull request in the repository where the fix is needed. Help with this project is greatly appreciated!
2. **Create an issue:** If you can't create a PR to fix it, simply open an issue. I'll see what I can do to implement the fix/idea.
